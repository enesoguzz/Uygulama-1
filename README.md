# Uygulama-1

Türkiye'deki özel öğrenci yurtlarını öğrencilerin ve velilerin yurda gitmeden, bütün detaylarıyla inceleyebildiği platform. İlk bölge: İstanbul Avrupa Yakası.

Çalışma adı: **Yurtrota** (geçici)

## Dokümanlar

- [Tanım dokümanı](docs/TANIM.md): ürün, kapsam, ekranlar, veri modeli, yol haritası
- [Tasarım rehberi](docs/TASARIM.md): renkler, yazı tipleri, bileşenler ve onaylanmış ekranlar (`docs/tasarim/`)
- [Gelecek fikirler](docs/GELECEK-FIKIRLER.md): ilk sürüme girmeyen fikirler
- [CLAUDE.md](CLAUDE.md): agent'ların çalışma kuralları
